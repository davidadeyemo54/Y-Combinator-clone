Lecture Note on Basic HTML Tags and Elements

In this lecture, I learned some of the most common HTML tages and elements used in creating and structuring webpages. Each tag plays an important role in how text and information are presented on a webpage. These include the following:

  • Heading tags <h1> to <h6>: The heading tags <h1> to <h6> are used to define different levels of headings. The <h1> tage represents the main or most important heading, while <h6> represents the smallest or least important one. These tages help in organizing content and make it easier for readers to understand the sturcture of a web page. For example, <h1> is often used for the title of a page, and the smaller headings like <h2> or <h3> are used for subtopics.

  • The paragraph tag <p>: The <p> tag is used to define a paragraph. It separates blocks of text, making content easier to read. Everything written inside a paragraph tage appears together as one block of text, and the browser automatically adds space before and after each paragragh for proper formatting.

  • The line break tag <br>: The <br> tag also known as the line break tag, is used to move text to the next line without starting a new paragraph. It does not need a closing tag. For exmaple, when we write "Hello<br>World", the browser displays "World" on a new line directly below "Hello".

  • The formatting tags <em>, <i>, and <b>: The <em> tag is used to emphasize text, and it usually appears in italics on a web page. It is often used to show importance or stress on a word or phrase. The <i> tag also makes text italic but is used mainly for stylistic purposes, such as writing foreign words, names of books, or technical terms. The <b> tag makes text bold, which is useful for highlighting or drawing attention to specific words or phrases in a document.

In conclusion, these HTML tages form the foundation of web page structure and text formatting. They help to organize content, create headings and paragraphs, emphasize impoortant points, and improve the overall readability of a web page. Understanding how to use them correctly is an essential step in learning how to design and build web pages.
